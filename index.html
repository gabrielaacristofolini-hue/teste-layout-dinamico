Teste: presell + P1 com layout dinâmico

A presell leva para a P1 com uma utm_source na URL, e a P1 mostra o layout daquela source.

1. Presell

Arquivo presell.html. Responda as perguntas e, no último passo, escolha qual utm_source enviar.

Abrir a presell

2. P1

Arquivo p1.html. É uma URL só, e o layout muda pela utm_source:

  • p1.html?utm_source=source1 → Layout 1
  • p1.html?utm_source=source2 → Layout 2
  • p1.html?utm_source=source3 → Layout 3
  • p1.html sem source → Layout 1 (padrão)
